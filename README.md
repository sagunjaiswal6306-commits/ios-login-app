# iOS Login App

## Overview
This project demonstrates a login system using Swift and MVVM architecture with validation and service layer.

## Architecture
- Model: User data
- ViewModel: Handles validation and login logic
- View: Displays output (simulated)
- Service: Handles login API logic

## Features
- Email validation
- Password validation
- Clean MVVM structure
- Separation of concerns

## Tech Stack
- Swift
- MVVM Architecture

## Flow
View → ViewModel → Service → Response

## Note
This project focuses on logic and architecture (built without macOS environment).
